## Projects

### ✅ [01 — Business Performance Dashboard](./01_Business_Performance_Dashboard)
**Tools:** Excel, Python (pandas, matplotlib)
Analysed 12 months of transactional data (R8.2M revenue, 35.8% gross margin) for a simulated industrial services business. Built validation checks, pivot tables and a KPI dashboard. Found a 55% revenue decline driven by falling deal volume rather than deal size, and that Service earns ~45% margin versus ~25% on Product — insights that reshaped the sales recommendations.
